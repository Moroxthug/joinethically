# JoinEthically

An independent editorial, ratings, and community platform for ethical products, ethical
companies, good living, and doing good — built on the `joinethically.com` domain.

This repo is currently in the planning stage. See [`docs/brand-and-site-plan.md`](docs/brand-and-site-plan.md)
for the brand direction, site architecture, ratings methodology, revenue model, design system, and
phased roadmap. Two interactive prototypes were shared alongside this plan: a homepage design
mockup, and a Studio admin tool (article editor with live preview + scorecard fields, and a
drag-and-drop homepage organiser with layout templates).

No application code has been written yet — next step is agreeing the plan above before scaffolding
the actual Next.js site and wiring these admin tools to a real CMS/backend.
